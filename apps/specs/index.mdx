---
title: "Hiaka Civic Stack"
description: "A GovStack-like civic participation stack for transparent, inclusive and interoperable digital public services."
---

Hiaka is an open-source Civic Stack for building transparent, inclusive and
interoperable digital participation services.

The hub is organized around two essential concepts:

```text
Civic Stack Model
  defines the components of the stack

Civic Stack Specs
  define specs and conformance for those components
```

The Civic Design System is part of the Civic Stack Model. It generalizes Civic
Patterns through an intent-driven and semantic model: intents, semantic
language and patterns.

The Civic Stack Model is organized around:

```text
Civic Blueprints
  compose Civic Modules
  and Civic Design System patterns
  with support from Shared Digital Services
```

Civic Stack Specs specify those model components: modules, design system,
blueprints, shared services, APIs, events, authorization, interoperability and
conformance.

The hub combines a Payload-powered landing site with this Mintlify-powered
specification portal.
