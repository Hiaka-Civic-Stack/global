description: "The conceptual architecture for composing reusable civic services."
---

The Civic Stack Model explains what Hiaka is made of.

It defines how public participation services are composed from reusable
concepts instead of one hard-coded application.

## Composition Model

```text
Civic Blueprints
  compose Civic Patterns
    coordinate Civic Modules
      consume Shared Digital Services
```

## Responsibilities

The Civic Stack Model owns:

* Civic Modules;
* Civic Patterns;
* Civic Blueprints;
* Shared Digital Services;
* composition rules;
* architectural boundaries.

The model does not define visual interaction details. Those belong to the
Civic Design System. It also does not replace implementation contracts. Those
belong to the Civic Stack Specs.

## First Reference Slice

Public Consultation v0 is the first concrete blueprint used to validate the
model through Participation, Contribution and Accountability.
