The Civic Design System is the Civic Stack Model component for designing civic
technology experiences.

It is both a civic-tech design framework and an experience standard that
products can use for conformance review. It is not the Hiaka hub UI, Payload,
shadcn or `packages/ui`.

It generalizes the former Civic Patterns layer. Patterns such as inform,
consult, contribute, deliberate, decide and account now live inside the Civic
Design System.

## What It Owns

The Civic Design System owns:

* civic experience principles;
* experience standards;
* Civic Patterns;
* accessibility and localization expectations;
* experience conformance;
* design-system governance.

It does not own module business rules. Those belong to Civic Modules.

It does not own blueprint lifecycle contracts. Those belong to Civic
Blueprints.

## Specs Boundary

Civic Design System specs are part of Civic Stack Specs because Civic Stack
Specs specify the components of the Civic Stack Model.
