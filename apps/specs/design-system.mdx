The Civic Design System is Hiaka's experience language.

It defines how civic technology interfaces should behave, guide, reassure and
include people across public participation services.

It is inspired by Radius as a design-system meta-framework, not as a ready-made
component kit. For Hiaka, that means design is not decoration. It is part of
public trust.

## Responsibilities

The Civic Design System owns:

* civic UX principles;
* design tokens;
* component hierarchy;
* interaction patterns;
* accessibility and localization expectations;
* design-system governance and adoption.

It does not own civic domain rules. Domain rules belong to the Civic Stack
Model and are implemented through the Civic Stack Specs.

## Core Layers

```text
Civic principles
  -> design tokens
  -> component hierarchy
  -> civic interaction patterns
  -> governance
  -> adoption and quality
```
