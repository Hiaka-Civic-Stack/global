Public Consultation v0 validates the first concrete composition of Hiaka.

<Note>**Status: orientation draft.** Sprint 4 will apply the full [Blueprint
Profile](/framework/profiles/blueprint) and [Common Spec
Structure](/framework/common-spec-structure) to this reference process.</Note>

```text
Institution creates consultation
→ Institution publishes consultation
→ Participant submits contribution
→ Contribution is published
→ Institution responds
→ Institution creates commitment
→ Commitment progress is updated
→ Participant sees implementation progress
```

Initial modules involved:

* Participation
* Contribution
* Accountability
