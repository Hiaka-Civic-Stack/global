---
title: "Repository Strategy"
description: "How the Hiaka hub and implementation repositories fit together."
---

The Hiaka hub is a Turborepo monorepo.

```text
apps/landing
apps/specs
packages/ui
packages/content
packages/config
```

Civic Module implementations live in separate repositories so that each module
can keep its own contracts, tests and release cycle.

The Civic Design System should also have a future dedicated repository as a
component of the Civic Stack Model. That repository is expected to contain its
specs, tokens, UI component reference implementation, Figma bridge, examples
and conformance guidance.

The hub's `packages/ui` package remains local hub UI infrastructure. It is not
the canonical Civic Design System implementation.
