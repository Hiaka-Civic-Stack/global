---
title: "Civic Modules"
description: "Reusable civic capabilities that can be composed into different public participation services."
---

Initial modules:

* Participation
* Contribution
* Deliberation
* Decision
* Accountability

Each module owns its domain model, business rules, application use cases,
permissions, events, API contracts and validation rules.

## Specification Profile

Future Module specifications use the [Module Profile](/framework/profiles/module)
and the shared [Common Spec Structure](/framework/common-spec-structure).

The profile keeps Module contracts reusable across Blueprints and requires
explicit domain, API, event, authorization, persistence and test boundaries.
