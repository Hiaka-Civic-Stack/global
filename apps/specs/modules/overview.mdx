---
title: "Civic Modules"
description: "Reusable civic capabilities that can be composed into different public participation services."
---

Initial modules:

* Participation
* Contribution
* Deliberation
* Decision
* Accountability

Each module owns its domain model, business rules, application use cases,
permissions, events, API contracts and validation rules.

## Module Specs v0

The first implementation-ready specifications cover:

* [Participation](/modules/participation);
* [Contribution](/modules/contribution);
* [Accountability](/modules/accountability).

They follow the [Module Specification Baseline](/modules/specification-baseline)
and define reusable capabilities independently from any Civic Blueprint.
Public Consultation v0 validates their composition but is not a runtime or
normative dependency of the Modules.

Deliberation and Decision remain overview-level concepts and are outside the
v0 critical path.

## Specification Profile

Module specifications use the [Module Profile](/framework/profiles/module)
and the shared [Common Spec Structure](/framework/common-spec-structure).

The profile keeps Module contracts reusable across Blueprints and requires
explicit domain, API, event, authorization, persistence and test boundaries.
