## Participation NFRs

| ID | Requirement | Expected evidence |
| --- | --- | --- |
| `PART-NFR-001` | Lifecycle transitions **MUST** be atomic, deterministic and reject stale aggregate versions. | State-machine, concurrency and persistence tests |
| `PART-NFR-002` | Time-based opening and closure **MUST** use an injectable clock and documented timezone rules. | Clock-boundary and timezone tests |
| `PART-NFR-003` | The same policy version and input attributes **MUST** produce the same eligibility decision. | Determinism and adapter contract tests |
| `PART-NFR-004` | Eligibility processing **MUST** minimize attributes and **MUST NOT** expose legal identity publicly by default. | Data-flow, privacy and representation tests |
| `PART-NFR-005` | Public process queries **MUST** be paginated and benchmarked against deployment-defined latency and capacity targets. | Repeatable workload report |
| `PART-NFR-006` | Outcome and lifecycle history **MUST** remain reviewable after completion or archival according to retention policy. | Retention and recovery tests |

## Test Expectations

Required evidence includes domain invariant tests, application command/query
tests, API contract tests, event producer tests, authorization denial tests,
audit integration tests, persistence concurrency tests and every conditional
port's adapter tests.
